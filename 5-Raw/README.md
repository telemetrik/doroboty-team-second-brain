# Udostępnione źródła

Przechowuj tutaj dopuszczone do udostępnienia materiały i wyciągi. W podsumowaniu źródła opisz pochodzenie, zakres i ograniczenia. Do zewnętrznego źródła możesz linkować ze strony wiedzy. Gdy źródło jest zamknięte, przygotuj zrozumiały wyciąg albo udostępnialną relację osoby, która widziała materiał.
